# O3 Car Spaa — picture prompts for Google Flow

## How to generate
- **Image mode, square 1:1**, generate **4 options**, and keep the best one.
- **Attach a style reference every time**, for example `client/public/illustrations/ac.webp` or `mechanic.webp`.
- **Save each file with the exact name shown** (for example `lib-graphene.png`), then paste them all into the chat. I'll add them to the app.
- If a result looks cluttered, add `single object only, no people, no scene, no floor` to the end of the prompt.
